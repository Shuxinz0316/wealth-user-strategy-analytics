# 指标口径与分析标准

## 生命周期

- 注册：`register` 事件。
- 开户：首次 `account_open` 事件。
- 首投：首次 `buy` 交易。
- 复投：累计至少两笔 `buy` 交易。
- 沉睡：截至观察期末，距最后一次访问超过 60 天。
- 活跃投资者：至少一笔申购且最近 60 天有访问。

生命周期阶段互斥，按用户达到的最深阶段与当前活跃状态标记。

## 漏斗

- 访问率 = 至少访问一次的注册用户 / 注册用户。
- 开户率 = 开户用户 / 注册用户。
- 首投率 = 首投用户 / 开户用户。
- 复投率 = 复投用户 / 首投用户。
- 端到端转化率 = 复投用户 / 注册用户。

漏斗先聚合到一名用户一行，再汇总渠道，避免事件表和交易表连接造成重复计数。

## 留存

按注册月建立 cohort。M0 将注册视为当月活跃，M1—M6 要求对应自然月存在 `app_visit`。结果使用 cohort 人数作分母，整体曲线用各 cohort 人数加权。

## 资产与交易

- AUM（简化）= 累计申购金额 − 累计赎回金额。
- 净流入 = 当月申购 − 当月赎回。
- 赎回率 = 赎回金额 / 申购金额，可按月份或产品计算。
- 收入代理指标 = 实验后 30 日人均购买金额；本项目没有平台费率，因此不称为真实收入。

## 实验

- 核心指标：30 日购买率。
- 先导指标：7 日点击率。
- 护栏指标：30 日留存率、触达失败率、风险适配投诉率（真实上线必须接入，模拟数据未生成投诉）。
- ITT：所有被随机分配的用户进入分母，不因是否送达而剔除。
- MDE：双侧 5% 显著性、80% power，围绕基准转化率计算每组样本量。

## 因果推断

DID 回归：`active_30d ~ pilot_group + pilot_group×post_period + month fixed effects`，标准误按用户聚类。交互项是活动带来的增量活跃率。真实应用需进一步检验平行趋势、同期政策和样本构成变化。
